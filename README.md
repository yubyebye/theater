# 江苏省科学家精神戏剧展示 · 静态网站

展示江苏高校原创“科学家精神”题材剧目的静态站点，纯 HTML / CSS / 原生 JavaScript，无构建步骤，可直接部署于 GitHub Pages。

## 在线访问

部署后地址形如：`https://<用户名>.github.io/<仓库名>/`

## 板块

- **剧目库（首页）**：剧目卡片（剧名、主题、200 字以内剧情简介、剧照占位图），支持关键词搜索与题材筛选，点开卡片查看剧目详情档案。
- **活动动态**：新闻按时间倒序排列，每条含日期、标题、摘要，并支持观众评论（评论保存在浏览器本地 localStorage）。
- **关于**：平台说明与首期参与高校。

## 目录结构

```
site/
├── index.html              # 单页入口
├── assets/
│   ├── css/style.css       # 样式
│   ├── js/data.js          # 剧目 / 动态数据（在此增补剧目）
│   ├── js/main.js          # 搜索、筛选、弹窗、评论、动效
│   └── stills/*.svg        # 剧照占位图（聚光灯风格，脚本生成）
└── tools/gen_stills.py     # 占位图生成脚本
```

## 新增剧目 / 动态

编辑 `assets/js/data.js`：向 `PLAYS` 追加一条（含剧名、学校、主题、简介等字段），或向 `NEWS` 追加一条（日期倒序自动排列）。剧照占位图可运行 `python tools/gen_stills.py` 生成新的序号版本。

## 本地预览

```
python -m http.server 8765
# 打开 http://127.0.0.1:8765
```

## 数据来源

剧目资料整理自各高校官网、官方公众号及公开报道（原始整理表：`戏剧展示详细信息.xlsx`），仅供学习交流。
